# Rocom — Robot-Enterprise Integration Standard

> Edition 2026a (draft) · Owned by ROCOM (CVR 46774043)

Rocom is an open standard for integrating robots, human workers,
task systems, and building infrastructure in healthcare environments.
It defines the protocol bindings, capability profiles, and conformance
requirements that enable heterogeneous systems to interoperate — so
hospitals and municipalities can deploy multiple robot brands without
custom integration per vendor.

## Who Rocom Is For

- **Hospital IT directors** specifying robot procurement without
  vendor lock-in
- **Robot manufacturers** implementing open integration for
  healthcare procurement qualification
- **Building operators** managing shared infrastructure (doors, lifts,
  charging docks) across independent robot fleets
- **Municipalities** requiring auditable, secure robot deployments
  with independent certification

## Certification

Rocom certification is performed by independent ICT providers with
ISO 27001 competence under ROCOM Board oversight. The secretariat
does not certify its own implementations.
See [Governance](governance.html) and Sup-005.
