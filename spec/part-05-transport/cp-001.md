# Correction Proposal — Pin VDA 5050 Version

## CP-001 — Pin VDA 5050 Version to 2.1

| Field | Value |
|-------|-------|
| **CP Number** | CP-001 |
| **Title** | Pin VDA 5050 version to 2.1 |
| **Status** | PROPOSAL |
| **Edition** | 2026a |
| **Affected Part** | Part 5 — Transport (PROFILE.md §2) |
| **Affected Requirements** | P-2.1.1 through P-2.1.5 |
| **Depended On By** | Sup-003 (BMS Infrastructure Contract) |

## Problem

The Rocom Healthcare Profile references "VDA 5050" throughout without pinning
a specific version. VDA 5050 has multiple versions in circulation (1.0, 1.1, 2.0, 2.1).
Without a pinned version:

- Conformance testing cannot verify against a fixed baseline
- Supplements (e.g., Sup-003 BMS Infrastructure Contract) cannot establish stable references
- Implementers may target incompatible versions
- The topic naming convention (`vda5050/`) is ambiguous across versions

## Correction

Add a normative version statement to Part 5 §2, immediately before §2.1 (Conformance Levels):

```markdown
## 1.1 Normative References

This profile is based on **VDA 5050 version 2.1** (VDA 5050-2, Release 2.1, 2023).
All references to "VDA 5050" in this profile refer to this specific version unless
explicitly stated otherwise.

The VDA 5050 topic namespace `vda5050/` and message schemas defined in VDA 5050 v2.1
are used without modification. Rocom extensions use the separate `rocom/v0/` namespace.
```

## Rationale

- VDA 5050 v2.1 is the latest stable release with mature topic schemas
- v2.1 introduced the `vda5050/factsheet` topic used by P-2.1.1
- Sup-003 (BMS Infrastructure Contract) references VDA 5050 transport
  topics and requires a fixed baseline for its conformance mapping
- All Rocom L1 coordination requirements (P-2.1.1–P-2.1.5) are defined
  against the v2.1 topic set

## Impact

- **Normative change:** Adds §1.1 Normative References to Part 5
- **No breaking change:** Existing implementations targeting VDA 5050 v2.1
  are unaffected. Implementations targeting earlier versions may need updates
  to match v2.1 topic schemas.
- **Dependencies:** Unblocks Sup-003 normative specification.

## Commitment

Tech Happens Europe ApS commits to maintaining VDA 5050 v2.1 as the baseline
until the next Edition cycle. Migration to a newer VDA 5050 version requires
a full Part revision.
