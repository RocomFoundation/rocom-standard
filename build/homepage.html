Governance

Open standard for healthcare robot orchestration

Rocom defines the contracts between hospitals, robot vendors, and workforce systems so that heterogeneous robot fleets can be allocated, tracked, and audited across shared infrastructure — without vendor lock-in.

Explore the standard Governance
Edition 2026a (draft) · CC-BY 4.0 · Source on GitHub

Robot

Agent identity, capability declarations, and VDA 5050 transport binding — the contract between robot and orchestrator.

Infrastructure

Shared resources — lifts, doors, docks — with authority models, capacity, and time-bound grants.

Workforce

Human agents, availability windows, and cross-allocation with robot fleets under unified priority.

Task

Task source contracts, priority scales, chain-of-custody tracking, and compliance event auditing.
